Hey everyone,

One of the biggest hurdles in using Flux or Midjourney for real commercial e-commerce is prompt consistency across multiple camera angles. If you prompt each angle manually, the colors drift, logos change, and the fabric texture looks completely different from the front to the back.

I created **Packshot-Prompt**—an open-source agent skill for Google Antigravity, Claude Code, and custom AI agents that automates the entire product photography prompt engineering process.

1. **Visual Product Audit:** You upload 1–5 photos of a garment. The agent extracts weave, hardware, collar cuts, and exact typography.

   - Front & Back Ghost Mannequin

All outputs are formatted as clean JSON ready to feed into Flux or Midjourney.

**Content:**

Hi HN,

Catalog e-commerce requires multi-angle consistency: front ghost mannequin, rear view, flat-lay, and on-model editorial. With generative image models (Flux, Midjourney, SD3), maintaining product fidelity and exact typography across these different angles is notoriously difficult.

Packshot-Prompt is an open-source agent skill that performs a multimodal audit of uploaded product photos and generates a structured JSON dictionary of production-grade prompts.

Key features:
- Four-part prompt assembly: Staging Lead + Structural Narrative + Typography Coordinates + Render-Spec Tail.
- Strict reference separation: Slices fit profiling (from worn images) away from material/color/logo extraction (from clean flat shots).
- Zara editorial style engine: Generates tonal monochrome companion outfits, naturalistic daylight falloff, and beauty crops.
- Zero-API execution: Runs in-context without calling external image generation APIs, allowing developers to plug the resulting prompts into their preferred rendering stack.
